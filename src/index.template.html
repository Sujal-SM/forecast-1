About the live forecast

How it works

Each time the page loads, the server pulls daily averages for PM2.5, PM10, NO2, SO2, CO and O3 from Delhi’s CPCB stations for the last 18 days. It computes each station’s AQI with the CPCB formula, averages the stations, rebuilds the model’s inputs and runs the live model.

Good to know

  • This live AQI is computed from daily station averages, so it can differ from the official CPCB bulletin, which uses hourly rolling values.
  • Days with no station data are filled from the day before, as in training. Filled days are listed above when they happen.
  • No weather or crop-fire data, so sudden spikes can be under-forecast.
  • An academic project. For health decisions, follow official CPCB and SAFAR forecasts.

Full results

How it works

Data

Daily Delhi readings from CPCB (Kaggle “Air Quality Data in India 2015-2020”): 2,009 days, 11 pollutants and AQI. Gaps are filled from earlier days only, and days without a recorded AQI are never used as targets.

Forecast

Inputs are known at the end of the forecast day: today’s pollutants, AQI from today and 1, 2 and 6 days ago, 3, 7 and 14-day averages, the season of the target day, and a Diwali flag. Linear Regression, Random Forest and Gradient Boosting each predict, and the forecast is their average. Training covers Jan 2015 to Jun 2019; Jul 2019 to Jun 2020 is the untouched test year.

Day types

Days are grouped by their pollutant mix. Using the day type as a forecasting input did not improve accuracy, so it is shown for understanding, not used in the forecast.

Limitations

  • No weather or crop-fire data, so sudden spikes are under-forecast. The largest miss was 209 AQI points on 3 Nov 2019.
  • Data end on 1 Jul 2020, and the test year includes the COVID-19 lockdown.
  • Dates before Jul 2019 are training days, so those forecasts are in-sample and look better than real use.
  • An academic project. For health decisions, follow official CPCB and SAFAR forecasts.
